# MI-TV: очистка памяти приставки

Android TV приложение для Xiaomi Mi Box (Android 9+). Показывает занятость RAM и хранилища, список установленных приложений с размером, датой последнего запуска и пометками, и выгружает фоновые процессы.

## Что умеет

- Показывает свободную RAM и свободное место во внутренней памяти.
- Показывает список приложений: размер, когда последний раз запускали, работает ли в фоне, системное ли.
- «Выгрузить фоновые приложения» останавливает фоновые процессы пользовательских приложений через `killBackgroundProcesses`.
- Нажатие на приложение открывает его системные настройки, где можно вручную остановить приложение или очистить кэш.

## Ограничения

- Принудительно остановить чужое приложение и видеть точную память каждого процесса без root или ADB нельзя. Поэтому приложение выгружает только фоновые процессы и отправляет в настройки для остального.
- Размер приложения и дата последнего запуска доступны только после разрешения «Доступ к статистике использования» (Настройки → Специальный доступ → Статистика использования).

## Сборка

Требуется Android Studio или Gradle 8.x и JDK 17.

```
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.
